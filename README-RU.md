# Рассмеши стримеров — серверная версия

Готовый проект: сайт + API для серверного сохранения заявок + парольная панель организатора.
Бесплатная публикация: Vercel (ссылка `*.vercel.app`) + Supabase Free (Postgres).

## Что уже сделано
- Форма заявки с проверкой обязательных полей и обязательной веб-камеры.
- Сохранение заявок в общей базе Supabase.
- Панель организатора с парольной проверкой.
- Экспорт загруженных заявок в CSV, который открывается в Excel.
- Ключ базы данных хранится только в переменных окружения сервера, не в HTML.

## Настройка (нужно сделать один раз)

### 1. Создай базу Supabase
1. Зарегистрируйся на https://supabase.com/ и создай новый проект на бесплатном тарифе.
2. Открой SQL Editor -> New query.
3. Скопируй содержимое `supabase-schema.sql` и нажми Run.
4. Открой Project Settings -> API (или Connect/API Keys, в зависимости от интерфейса) и скопируй:
   - Project URL
   - `service_role` / secret service key. Никому его не отправляй и не помещай в HTML.

### 2. Размести сайт на Vercel
1. Создай аккаунт на https://vercel.com/.
2. Создай новый GitHub-репозиторий и загрузи туда ВСЕ файлы этой папки (включая `api/`, `package.json`, `vercel.json`, `index.html`).
3. В Vercel нажми Add New -> Project и импортируй репозиторий.
4. В настройках проекта -> Environment Variables добавь:
   - `SUPABASE_URL` = Project URL из Supabase
   - `SUPABASE_SERVICE_ROLE_KEY` = секретный service role key из Supabase
   - `ADMIN_PASSWORD` = придумай длинный уникальный пароль панели организатора
5. Нажми Deploy. Vercel выдаст бесплатный адрес `https://имя-проекта.vercel.app`.

После изменения переменных окружения нужно заново сделать Redeploy.

## Как принимать заявки
- Участники открывают публичный адрес Vercel.
- Внизу сайта раскрывают «Панель организатора», вводят `ADMIN_PASSWORD` и нажимают «Загрузить заявки».
- Кнопка «Экспорт CSV для Excel» выгружает загруженные заявки.

## Важно о бесплатном варианте
- Бесплатные тарифы и лимиты сервисов могут меняться; проверь актуальные условия при регистрации.
- У бесплатной базы могут быть ограничения/пауза при неактивности.
- Не включай публичный доступ к таблице Supabase и не публикуй service role key.
- Панель использует общий пароль. Храни его отдельно и меняй, если он стал известен посторонним.
- В этом пакете нет автоматической защиты от спама/rate limiting; если ссылку массово распространять, добавь CAPTCHA и ограничение частоты запросов.
- Возрастной минимум в форме сейчас 13 лет; измени в `index.html` и `api/applications.js`, если правила твоего стрима другие.
